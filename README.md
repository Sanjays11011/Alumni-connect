# Heritage Hub

## Overview
Heritage Hub is an alumni association platform that connects students and alumni for networking, mentorship, and collaboration.

## Features
- User Authentication
- Alumni Networking
- Resource Sharing
- Real-time Messaging
- Responsive Design

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- REST API

## Installation

```bash
npm install
npm start
```

- Video Calling
- Job Referral Portal
